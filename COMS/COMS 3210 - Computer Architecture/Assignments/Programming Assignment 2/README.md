# Programming Assignment 2 - LEGv8 Disassembler

## Project Description
This assignment implements a LEGv8 disassembler that converts binary machine code into human readable assemply.

## Build and Run

### Compilation
Build the project using the provided script on Pyrite:
`./build.sh`

### Execution
Run the disassembler by passing a binary file as the first argument:
`./run.sh <binary_file>`
