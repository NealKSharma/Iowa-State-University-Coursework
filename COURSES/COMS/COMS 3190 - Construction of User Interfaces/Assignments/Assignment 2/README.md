## Project Description
This application is a AI Prompt Engineering Studio which helps users build better prompts by oranizing their ideas into various structured sections. Users can choose a prompt category, fill in required field then validate their input after that decide the configure output settings, and finally generate a final prompt that can be copied and used with an AI tool to achieve more accurate results.

## Setup Instructions
1. Open the project folder
2. Then install dependencies with `npm install`
3. Start the development server with `npm run preview`.
4. Then open the local Vite link shown in your terminal.


## Notes / Limitations
- This application heavily depends on the template data in `src/data/templates.json` if this file is missing or has invalid json the app will not work right
