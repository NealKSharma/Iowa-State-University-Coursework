## Project Description
In COM S 3090, we built a full-stack hospital management application designed to support
realistic patient and provider workflows. For COM S 3190, we are taking that same project
and rebuilding it as a responsive, front-end focused website to demonstrate strong user
interface design, clear navigation, and polished interactions.

Our website will emphasize usability and clarity for multiple user roles (patient, provider,
and admin). Rather than only showing features technically working, we want the site to feel
like a real product: consistent layout, readable pages, clear calls-to-action, and sensible
information architecture.
